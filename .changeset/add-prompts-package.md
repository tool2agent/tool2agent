Add @tool2agent/prompts package with reusable prompt fragments for LLMs.

This package provides:
- `tool2agentDescription`: A comprehensive description of the tool2agent protocol for system prompts
- `tool2agentToolPrefix`: The `[tool2agent]` string constant to mark tool2agent-enabled tools
- `withTool2AgentPrefix()`: Helper function to add the prefix to tool descriptions
